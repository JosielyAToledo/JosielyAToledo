
1. O que é um programa de computador?
````
É um conjunto de instruções escritas em uma linguagem de programação que orienta
o computador a realizar tarefas específicas.
````
2. O que é uma linguagem de programação?
````
É um sistema usado para escrever instruções que o computador pode entender e executar.
Possui regras de sintaxe e semântica, e é usada para criar programas de software.

````
   <ins>Semântica</ins>: significa dar instruções de um programa, o que faz durante a execução. 

   <ins>Sintaxe</ins>: conjunto de regras que define como as intruções devem ser estruturadas em uma ling. Programação, especifíca a forma correta de escrever comandos e expressoões. 

3. Exemplo de linguagem de programação:
   **Python, Java, C, C++, C#, JavaScript**

4. O que uma linguagem de programação de alto nível?
````
É uma linguagem mais próxima da ling. humana, fácil de usar e abstrata em relação ao hardware,
como python e java.
````
5. O que é uma linguagem de programação de baixo nível?
````
É mais próxima do hardware e exige maior controle sobre detalhes como memória. Assembly e ling. C.
````
6. Quais diferenças entre linguagens de baixo nível e alto nível?
   
    <ins>Abstração</ins>: Alto nível esconde detalhes do hardware, baixo nível oferece controle direito.
   
    <ins>Facilidade</ins>: Alto nível é mais fácil de usar, baixo nível exige mais conhecimento técnico.
   
    <ins>Controle</ins>: Baixo nível oferece mais controle sobre hardware.
   
    <ins>Portabilidade</ins>: Alto nível é mais portátil, baixo nível é específico para a arquitetura de hardware. 

7. Quem são os programadores?
````
Programadores são profissionais que escrevem, testam e mantêm códigos de software
para criar programas que executam tarefas específicas em computadores. 
````

8. Qual a diferença entre um algoritmo e um programa?
    
   **Algoritmo:**  
   É uma sequência de passos ou instruções para resolver um problema ou realizar uma tarefa específica. Não depende de linguagem de programação e pode ser descrito em termos gerais.

   **Programa:**  
   É uma implementação de um algoritmo em uma linguagem de programação, que pode ser executado por um computador. Um programa contém o código-fonte que segue a lógica do algoritmo para realizar a      tarefa desejada.

   **Diferença:**  
   Um algoritmo é a solução lógica de um problema, enquanto um programa é a tradução desse algoritmo em código executável por um computador.

9. Quais as características de um programa?
````
As características de um programa incluem: entrada e saída de dados, processamento eficiente,
produção de resultados corretos, portabilidade entre plataformas,
manutenibilidade para atualizações e segurança para proteção de dados.
````
10. O que é um código-fonte?
````
O código-fonte é o conjunto de instruções escritas por um programador em uma linguagem de programação,
que define a lógica de um programa antes de ser executado.
````
11. O que é código-fonte aberto?
````
Código-fonte aberto é software em que o código é acessível ao público, permitindo visualização,
modificação e distribuição por qualquer pessoa.
Exemplos de software de código aberto sistema operacional Linux e o navegador Mozilla Firefox.
````
12. O que é código-fonte fechado?
 ````
 Código-fonte fechado é software em que o código não é acessível ao público,
 sendo modificado e distribuído apenas pela empresa ou desenvolvedor responsável.
 ````
13. O que é um compilador?
````
Um compilador é um programa que traduz o código-fonte de uma linguagem de alto nível
para uma linguagem que o computador pode entender e executar.
````

14. O que é um interpretador?
````
Um interpretador executa o código-fonte linha por linha, traduzindo e executando
as instruções em tempo real, sem gerar um arquivo executável.
````
15. Qual a diferença entre compilador e interpretador?
    
    A principal diferença entre compilador e interpretador está na forma como eles executam o código:
````
 Compilador: Traduza o código-fonte inteiro de uma vez, criando um arquivo executável que pode ser executado posteriormente.
 A execução é mais rápida, pois a tradução ocorre antes da execução.
  
Interpretador: Traduz e executa o código-fonte linha por linha em tempo real.
Não gera um arquivo executável, e a execução tende a ser mais lenta devido à tradução contínua.
````
   O compilador realiza a tradução antes da execução, enquanto o interpretador faz isso durante a execução.


16. O que é uma IDE?

````
IDE (Ambiente de Desenvolvimento Integrado) é um software que reúne ferramentas como editor de código,
compilador, e depurador, facilitando o desenvolvimento de programas.
Exemplos incluem Visual Studio, Eclipse e IntelliJ IDEA.
````

17. Qual a diferença entre o DEV-C e o MinGW?

   - **Dev-C++** é uma **IDE** (Ambiente de Desenvolvimento Integrado) que fornece um editor de código, compilador e depurador, facilitando o desenvolvimento de programas em C e C++.
  
 - **MinGW** é um **conjunto de ferramentas** que inclui o compilador **GCC** (GNU Compiler Collection) adaptado para o Windows, permitindo compilar código C e C++ em sistemas Windows.

    **Dev-C++** é uma IDE que pode usar o **MinGW** como compilador. O **MinGW** é apenas o compilador e as ferramentas necessárias para a compilação, sem interface gráfica.
    

18. O que é uma variável?
 
    **Variável** é um espaço de armazenamento na memória que guarda dados temporários, com um nome e um tipo, e seu valor pode ser alterado durante a execução do programa.

19. O que é uma linguagem case sensitive?
    
    **Linguagem case sensitive** diferencia maiúsculas de minúsculas, tratando caracteres como `variavel` e `Variavel` como diferentes.
