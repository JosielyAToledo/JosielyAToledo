# Mini Projeto 1 - Lâmpada

Este projeto foi desenvolvido com base no tutorial de Fernando Leonid.

## Créditos

O código deste projeto foi inspirado no tutorial do canal do Fernando Leonid, disponível em:  
[https://youtu.be/4r0zOW9Zn-Y?si=aq3W38EgWY9NDkfq](https://youtu.be/4r0zOW9Zn-Y?si=aq3W38EgWY9NDkfq).  

## Estrutura do Projeto

- `html/`: Contém o arquivo HTML para a estrutura da lâmpada.
- `css/`: Arquivo CSS que define o estilo visual da lâmpada.
- `js/`: Arquivo JavaScript responsável pela funcionalidade e lógica da lâmpada.
